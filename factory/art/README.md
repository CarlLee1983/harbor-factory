# Factory art

`scene.png` and the 40 illustrations in `locations/` are new compositions made with Kenney’s **Tiny Factory 1.0** tiles and original pixel detailing. Kenney released the tile pack under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The [original upload by Kenney](https://opengameart.org/content/tiny-factory) and the [pack license](kenney-tiny-factory-license.txt) document the source.

The 24 sprites in `workers/` are original pixel drawings for this project. Each worker has a front, right-facing side, and back view. The sprites use transparent 24 × 28 px canvases and a shared ground line. Property illustrations use transparent 32 × 32 px canvases. The factory floor is an opaque 416 × 240 px image. Display the artwork with nearest-neighbor interpolation.
